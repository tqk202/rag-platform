# 差旅与报销管理规定（2026 年修订，含新旧标准对照）

**制度编号**：FIN-REG-002 ｜ **版本**：V7.1 ｜ **发布部门**：财务部 ｜ **生效日期**：2026-01-01
**配套文件**：《员工手册》（HR-REG-001）、《薪酬与绩效管理制度》（HR-REG-004）

## 一、出差审批

员工出差须提前填写《出差申请单》，注明出差事由、目的地、预计天数与预估费用，经部门主管审批后报行政部备案。单次出差超过三天的，须经部门负责人审批；跨省出差的，须经分管副总审批。

出差天数以交通票据与住宿票据日期为据，未实际发生的费用不得报销。

## 二、住宿标准（2026 新标准）

住宿费凭发票实报实销，但不得超过下表限额（每晚，元）。发票抬头须为公司全称"星辰云驰科技有限公司"，无发票或抬头不符的不予报销。

城市分档及住宿限额（元/晚）：
```
一线城市（北京上海广州深圳）  ≤ 600
二线城市                    ≤ 400
三线及以下城市              ≤ 300
同城当日往返不住宿          -
```

即：一线城市出差住宿标准是每晚不超过六百元，二线城市不超过四百元，三线及以下城市不超过三百元。

（2025 旧标准：一线 500、二线 350、三线 250，已废止，仅保留作对照，不适用。）

## 三、出差补贴（2026 新标准）

出差补贴按天计算，含餐费与市内交通，不须发票：

- 一线城市出差补贴每天一百二十元；
- 二线城市每天一百元；
- 三线及以下城市每天八十元。

补贴天数按出差自然日计算，出差不足半天的按半天计。员工出差期间公司提供住宿的（如入住分公司宿舍），住宿费不报销但补贴照发。

## 四、交通费报销

出差交通费实报实销：飞机经济舱、高铁二等座（出差超 6 小时的经批准可乘一等座）、长途汽车、市内出租车（保留票据）。自驾出差的，按每公里一块五的标准报销油费，另按实际里程补贴过路费，需附出发前与返程后里程表照片。

乘坐飞机须提前预订经济舱，升舱费用自理。因私绕道的交通费不予报销。

## 五、招待费

因业务需要招待客户的，须事前申请，注明招待对象、人数与预算。招待费标准为每人每次不超过三百元。招待费发票须附消费明细清单（列明菜品/金额），单笔超过一千元的须附客人名单及单位。

（2025 旧标准：招待每人每次不超过 260 元，已废止。）

## 六、报销流程与时限

报销单据须在费用发生后一个月内提交，逾期提交的须说明原因并经部门主管与财务总监批准。报销流程：

报销单提交后由部门主管审批，再经财务部门复核，全部通过后进入打款流程。报销款项在审批完成后五个工作日内发放到员工工资卡。

单笔金额超过两千元的报销，须附发票原件供财务查验；超过一万元的，须附发票原件并走线下纸质签批（部门负责人+财务总监双签）。

> 提示：财务复核主要核对——发票真实性与抬头、金额是否超标准、审批链是否完整、是否重复报销。重复报销按《员工手册》第七章纪律处分处理。

## 七、特殊情况

1. 出差期间生病住院的，凭医院证明按病假处理，费用按《薪酬与绩效管理制度》病假规定执行。
2. 出差期间因公使用个人车辆发生事故的，按公司车辆管理制度处理（该制度由行政部另行发布）。
3. 外币费用按报销当日汇率折算，附汇率截图。
4. （待补：2026 年海外出差补贴标准，尚未发布，海外出差请提前咨询财务。）
