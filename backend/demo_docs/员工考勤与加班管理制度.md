# 员工考勤与加班管理制度

**制度编号**：HR-REG-001 ｜ **发布部门**：人力资源部 ｜ **版本**：V4.1 ｜ **生效日期**：2026-01-01

## 一、目的与适用范围

为维护正常的工作秩序，规范员工考勤与加班管理，特制定本制度。本制度适用于公司全体在职员工，外派、兼职人员参照执行。

## 二、打卡制度

公司实行上下班打卡考勤制度，标准工作时间为每周一到周五的早上九点到下午六点，中午休息一小时。

员工上下班均需在公司考勤系统打卡，未打卡且未补办手续的，按迟到或早退处理。连续迟到三次，记一次旷工。考勤记录每月由人事部门汇总核对一次，作为工资发放和绩效考核的依据。

## 三、考勤异常处理

员工因公外出、外勤办事等原因无法打卡的，须在当日内通过系统提交补卡申请，说明外出事由，经直属主管确认后生效。

忘打卡的每月可补卡两次，超过次数需写书面说明。员工对当月考勤记录有异议的，可在考勤汇总公布后三个工作日内向人事部门提出申诉，逾期视为认可记录。

## 四、加班申请流程

员工因工作需要加班时，须提前一个工作日在公司系统提交加班申请，写明加班事由和预计时长，经直属主管审批后生效。

未提前申请或未经审批的加班，不予认定。紧急情况无法提前申请时，可在加班后次日补交申请并说明原因，由主管确认。加班时长按月统计，月底由系统推送确认单，员工须在三个工作日内核对签认。

## 五、加班费计算标准

经审批认定的加班，按以下标准计算加班费：

| 加班时段 | 加班费倍率 |
| --- | --- |
| 工作日加班 | 平时工资的 1.5 倍 |
| 休息日加班 | 平时工资的 2 倍 |
| 法定节假日加班 | 平时工资的 3 倍 |

工作日加班按平时工资的1.5倍计算，休息日加班按2倍计算，法定节假日加班按3倍计算。

员工也可以选择将加班时长折算为调休，调休须在加班发生后六个月内使用完毕，逾期作废。加班时长按月结算，随当月工资一并发放。

## 六、请假管理

员工请事假、病假须提前申请，病假需附医院证明。请假审批通过后方可休假，未经批准擅自缺勤的按旷工处理。

事假每次最长不超过三天，超过需部门负责人和人事部门双重审批。调休与年假的具体使用规则见《年假与休假管理制度》。

## 七、弹性工作与远程办公

研发、设计等岗位经部门负责人批准后，可实行弹性上下班，核心工作时间仍为上午十点到下午四点。

每周可申请一天远程办公，远程办公期间须保持工作设备在线并按时参加线上会议。弹性或远程安排须提前一天在系统备案，便于考勤统计。

## 八、附则

本制度由人力资源部负责解释与修订，自发布之日起执行。加班与考勤数据的电子记录保存期限为三年，作为劳资争议处理依据。
